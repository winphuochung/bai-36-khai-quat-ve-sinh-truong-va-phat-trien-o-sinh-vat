# Web/app học tập — KHTN 7, Bài 36

**Bài 36: Khái quát về sinh trưởng và phát triển ở sinh vật**
Môn Khoa học tự nhiên 7 — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống.

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng gồm:
1. Cây cam lớn lên theo thời gian (5 giai đoạn vòng đời: hạt → hạt nảy mầm → cây con → cây trưởng thành → ra hoa, kết quả).
2. Các giai đoạn phát triển của ếch (4 giai đoạn: trứng đã thụ tinh → ấu trùng (nòng nọc) → nòng nọc mọc chân → ếch trưởng thành).

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong thư mục

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_KHTN7_Bai36.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — mã Apps Script ghi điểm vào Google Sheets (tab KetQua).
- `assets-flow/` — 3 ảnh nền (1376×768) + logo giáo viên.
